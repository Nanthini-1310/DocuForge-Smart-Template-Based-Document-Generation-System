# DocuForge - Document Generation Platform

A powerful document generation application built with React, Vite, and Cloudflare Workers.

## Features
- Google OAuth authentication
- Document template management
- PDF and DOCX document generation
- Secure session management
- Cloudflare Workers backend

## Quick Start

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```
Visit `http://localhost:5174`

### Building
```bash
npm run build
```

### Deployment
```bash
wrangler deploy
```
